# Weather App

App de clima em HTML, CSS e JavaScript puro. Digite uma cidade e ele mostra temperatura, descrição, umidade e vento usando a API do [OpenWeather](https://openweathermap.org/api). Se a cidade não existir, mostra uma tela de "não encontrado".

## Arquivos

- `index.html`, `style.css`, `index.js`: a página.
- `*.png`: ícones de clima e da tela 404.

## Como rodar

1. Crie uma chave gratuita no OpenWeather.
2. Em `index.js`, troque `const APIKey = 'API'` pela sua chave.
3. O HTML busca as imagens em `images/`. Crie essa pasta e mova os `.png` para lá.
4. Abra o `index.html` no navegador.
